דוח פתיחה – Take Me Out (15.11.2026)

1. מה הבנתי
- אפליקציית ווב בעברית (PWA, קוד אחד לנייד ולמחשב) להזמנה ותשלום של סירות מנוע עד ~10 מ' ביוון, לשוק הישראלי. פיילוט בקיץ 2027. סירות בלי רישיון – מוצר משלים ליום אחד.
- הגוף המשפטי: מגדל דנילוב בע"מ (ח.פ. 514942119). כל הכסף נגבה בישראל דרך Grow (סליקה) ו-Morning (חשבוניות) הקיימים.
- מחירים ביורו + מחשבון לשקלים. תשלום בשקלים לפי שער יום התשלום + מרווח קבוע; עמלות סליקה על הלקוח; כל התוספות נגבות מראש.
- לוח תשלומים: הלקוח משלם יום לפני כל תשלום למפעיל (חצי בהזמנה, חצי חודש לפני ההפלגה). ביטול לפי מדיניות המפעיל + גילוי מורחב; דמי השירות נשארים אצלנו.
- מפעילים דרך מערכת הזמנות אחת בפיילוט (MMK או NauSYS – עוד לא הוחלט), רק מפעילים מאומתים Silver/Golden. MMK: sandbox עד סוף מרץ 2027, נתונים אמיתיים מאפריל 2027 (איש קשר: Zdenko).
- אין שום תלות במערכת של Alexandros Bertsiadis.
- כניסה בקוד חד-פעמי בוואטסאפ (Green API על מספר ישראלי ייעודי), גוגל/אפל כאפשרות. שכבת שליחה אחת שמאפשרת מעבר ל-WhatsApp Cloud API. שיווק ותזכורות לא דחופות – רק אחרי שבת וחג.
- עוזר AI בעברית, דוח תקלה מובנה שמתורגם ליוונית עם תמונות ווידאו, המלצה על בסיסי יציאה לפי טיסות ישירות (עדכון שבועי).
- הבק-אופיס אוטומטי לגמרי; חגי מטפל רק בחריגים.
- כללים: מתגים כבויים לכל מה שפונה ללקוח, בלי מחיקות (רק סימון/הסתרה), סודות רק דרך הלוח או משתני סביבה, לפני פריסה: בדיקות → גיבוי → בדיקה בפרודקשן → פריסה, ונקודת חזרה בכל דוח.
- לא מחליט לבד: ביטוח, בדיקה משפטית, איש גיבוי, גובה דמי השירות, אזורי השקה, MMK מול NauSYS.

2. מחסנית מוצעת (קרוב לריזורט)
- צד לקוח: Vite + React 19 + TypeScript + Tailwind 4 (RTL מלא), vite-plugin-pwa.
- שרת: Vercel Functions (תיקיית api) + Vercel Cron (שערי מטבע, לוח טיסות, תזכורות תשלום, סנכרון זמינות).
- נתונים: Supabase – Postgres עם RLS, Auth (קוד וואטסאפ מותאם + Google/Apple), Storage (צילומי רישיון, תמונות ווידאו של תקלות).
- AI: Claude API לעוזר ולתרגום דוחות התקלה ליוונית (הצעה – לאישורך).
- בדיקות: Vitest ללוגיקה (מחירים, לוח תשלומים, ביטולים, שעות שקטות), Playwright לזרימות.
- כסף נשמר במספרים שלמים (סנטים/אגורות) עם השער והמרווח של כל תשלום.
