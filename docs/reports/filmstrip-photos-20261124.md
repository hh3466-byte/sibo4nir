# דוח — רצועת תמונות אופקית דומיננטית (filmstrip marquee) בכרטיסי העצירה וה-detail (24.11.2026)

ענף: `feat/live-map` (לא מוזג ל-`main`).

## מה נעשה
1. **אזור תמונה דומיננטי (`app/globals.css`, `components/LiveMap.tsx`):**
   - גובה `.tmo-stop-modal-media` הוגדל מ-`130px` ל-**`290px`** (ובמובייל `220px`), והכרטיס הורחב ל-`max-width: 480px` ו-`max-height: min(88%, 600px)` כדי ש-3–4 תמונות יוצגו בפרופורציה עריכתית נדיבה והתמונה תהיה האלמנט המרכזי.
2. **רצועת תמונות אופקית (filmstrip marquee) בלולאה רציפה:**
   - `PhotoCarousel` הומר לרצועה אופקית (`tmo-filmstrip-track`) שמציגה **3–4 תמונות בו-זמנית** זו לצד זו (`flex: 0 0 155px` בדסקטופ, `120px` במובייל) עם גלילה אופקית רציפה וחלקה בלולאה אינסופית (`@keyframes tmoMarquee`).
   - **עצירה בריחוף עכבר (`pause on hover`):** `.tmo-stop-modal-media:hover .tmo-filmstrip-track { animation-play-state: paused; }`.
   - במקרה של תמונה אחת בלבד — מוצגת תמונה מלאה סטטית ללא גלילה.
3. **כיסוי מלא:** הרצועה חלה על תמונות המקום בכרטיס העצירה הראשי וגם על תמונות ה-detail של טברנה ומלון/לינה.
4. **ללא שינוי בקרוסלות הבחירה:** קרוסלות המלונות והטברנות (`OptionCarousel`, אופציה אחת בכל רגע עם מונה `2/3`, נקודות וחצים), התיאור, הגלילה הפנימית ו-footer ה-`sticky` של כפתור "המשך" נשארו כפי שהיו.
5. **עדכון ספק:** `docs/specs/map-animation.md` עודכן.
