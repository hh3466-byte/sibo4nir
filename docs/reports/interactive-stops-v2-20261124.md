# דוח — שכלול עצירות אינטראקטיביות (pop-out מהמפה, המשך sticky ותצוגות detail) (24.11.2026)

ענף: `feat/live-map` (לא מוזג ל-`main`).

## מה נעשה
0. **עדכון ספק (`docs/specs/map-animation.md`):** נוסף סעיף **"עצירות אינטראקטיביות באנימציה"** עם כל 4 הדרישות לפני כתיבת הקוד.
1. **פתיחה מתוך נקודת העצירה על המפה (`components/LiveMap.tsx`, `app/globals.css`):**
   - עם ההגעה לכל עצירה מחושבות קואורדינטות המסך של הנקודה (`map.project(coord)`), מופיעה טבעת דופק בפליז על המרקר, וכרטיס העצירה "מבצבץ" וגדל החוצה ישירות ממנה באנימציית `scale + fade` (`transform-origin` מכוון לנקודת העצירה).
   - המפה החיה נשארת גלויה מאחור (כולל `offset` עדין ב-`flyTo` כדי שהנקודה והכרטיס יישבו בנוחות זה לצד זה), והמיקום מתעדכן גם אם המשתמש מזיז את המפה.
2. **כפתור "המשך" קבוע (`sticky`):**
   - מבנה `flex-direction: column` עם אזור גלילה פנימי (`.tmo-stop-scroll`) ו-footer קבוע (`.tmo-stop-footer`) שבו כפתור **"המשך ← ..."** גלוי תמיד — לא נעלם בגלילה ולא בתוך תצוגות ה-detail.
3. **טברנות לחיצות → תצוגת detail:**
   - כל טברנה ברשימה היא כפתור לחיץ שפותח תצוגת detail: תמונה מלאה (מה-Storage), מה לאכול שם (`note` מה-DB), מקום מוכן ומסודר לתפריט מלא ולהמלצות/ביקורות נוספות, וכפתור `חזרה לטברנות →`.
4. **מלונות לחיצים → תצוגת detail + בחירה:**
   - כל מלון ברשימה הוא כפתור לחיץ שפותח תצוגת detail: תמונה מלאה, מחיר ללילה, תיאור ומקום מוכן לביקורות/תמונות נוספות, כפתור **"בחרו את המלון הזה ללינה"** / **"✓ נבחר ללילה הזה"**, וכפתור `חזרה ללינות →`.
- **אפס קריאות API חדשות:** שימוש אך ורק בנתונים ובתמונות שכבר ב-DB וב-Supabase Storage.
