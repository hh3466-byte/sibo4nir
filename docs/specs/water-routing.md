# ניתוב מים — שלא יחצה יבשה

מחליף את הקו הישר הזמני ב-`lib/geo/routing.ts`. השיטה הזאת כבר עבדה לנו בעבר (0 חציות יבשה על אותו אזור).

## קווי חוף (lon/lat)
- הוצא קווי חוף של הקיקלדים מ-Natural Earth: `npm i world-atlas topojson-client`, טען `land-10m`, `topojson.feature(...).features`, וסנן פוליגונים בחלון של אזור הפיתוח. שמור כפוליגוני lon/lat (לא צריך לצייר אותם — Mapbox כבר מציג את האיים; הם משמשים רק לניתוב).

## האלגוריתם
1. `inPoly(p, poly)` — ray-casting: האם נקודה בתוך פוליגון (יבשה).
2. `nearSeg(p, a, b)` — הנקודה הקרובה ביותר על קטע.
3. `avoid(p, polys, margin)` — אם נקודה על יבשה, דחוף אותה אל מחוץ לפוליגון, לקצה הקרוב + margin ימי קטן.
4. `clearLeg(a, b, polys)` — אם הקטע a→b חוצה יבשה: מצא את נקודת החדירה, הכנס detour סביב האי, ופצל רקורסיבית עד שכל תת-קטע נקי.
5. `buildRoute(stops)` — העבר כל leg דרך `clearLeg`, צופף נקודות (densify) לקו חלק.

## אימות
- דגום את כל נקודות הנתיב + אמצעי הקטעים ובדוק `inPoly` מול כל האיים. יעד: 0 חציות. הדפס את המספר בדוח.

## מסלולי דגל
- לשמור את נתיב המים המחושב של כל מסלול דגל ב-DB (רשימת נקודות lon/lat), כדי שהמפה תצייר אותו מיד בלי חישוב בזמן אמת. ניתוב חי נחוץ רק למסלולים חדשים מהמתכנן (חלק 2).
