# פקודת ביצוע — סבב 2 (ענף feat/live-map)

קרא קודם: docs/specs/map-animation.md, docs/specs/photos.md, docs/specs/water-routing.md, docs/brief-20261124.md.

0. מפתח Google Places נמצא עכשיו בלוח (מתחיל ב-AIza). קרא אותו מהלוח וכתוב ל-.env.local כ-GOOGLE_PLACES_API_KEY. הוסף גם לסביבת Vercel בעת פריסה. לעולם אל תדפיס אותו בטרמינל, בדוח או בקובץ שנכנס לגיט.

1. תיקוני מפה (סיום ואימות):
   - סמל סירה אמיתי (אם כבר בוצע — השאר).
   - המסלול לא חוצה יבשה בפועל על הלוויין: נתב לפי OSM coastline, ואמת בזום שאין חציית יבשה בשום מקום.
   - התחלה וסיום בנמל אמיתי (מרינת נאוסה בפארוס), לא אמצע מפרץ.

2. אנימציה (לפי docs/specs/map-animation.md):
   - מצב תכנון (ברירת המחדל): קו מקווקו ברור בדיוק על נתיב השיט, סירה מתקדמת ב-20 קשר, ושעון רץ שמציג ימים + שעות מצטברים.
   - מבנה שיאפשר בעתיד מצב "הפלגה בפועל" בצבע אחר ועל מיקום אמיתי (לא לממש עכשיו, רק להשאיר מקום).

3. מסלול דגל של שבוע:
   - "לב הקיקלדים" קצר מדי (יומיים). הארך אותו למסלול של כ-7 ימים: הוסף איים ועצירות נוספים בקיקלדים (geocode דרך Places), לינות ביבשה ומרחקים ימיים מציאותיים, כך שהשעון מראה שבוע.
   - בעתיד נחליף לתוכן ה-14 יום (לברי→קיקלדים) מגימיני.

4. Hero עם קרוסלה (לפי docs/specs/map-animation.md):
   - רקע מלא-מסך מתחלף מתוך public/img/hero.jpg ו-public/img/e1.jpg..e8.jpg (מפרצים, ים, אווירה), עם overlay כהה עדין כדי שהכותרת תישאר קריאה. בלי הגרדיאנט הירוק.

5. תמונות מקומות (לפי docs/specs/photos.md):
   - חבר את ה-places לתמונות אמיתיות מ-Google Places + cache ל-Supabase Storage (קריאה פעם אחת, שמירת ייחוס). טברנות ומלונות גם יוצגו עם תמונה.

6. בלי פנייה ללקוח, בלי כסף, בלי הודעות. כל המתגים כבויים. בלי מיזוג ל-main בלי "מאושר". שמור דוח בעברית ב-docs/reports ושלושה צפצופים.
